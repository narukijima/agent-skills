# Media rules — 同一Levelの媒体別適用

同じLevelでも、認知制約(C1〜C11、`levels.md`)の現れ方は媒体ごとに異なる。ここでは各媒体で支配的な制約と、Levelを下げるときの操作、媒体別のauto default候補、このSkillが所有しない領域を定義する。default候補はAudienceとPurposeが不明なときのfallbackであり、実測や明示指定を上書きしない。媒体の制作技術そのものは各制作Skillまたは利用側の責務であり、ここでは理解可能性の制約だけを与える。

## prose / article / documentation

- 支配的制約: C1〜C9。語彙、文構造、段落構成、専門語の接地位置、前提知識の宣言。
- Levelを下げる操作: 未接地term→初出で定義+具体例。深い従属節・条件の入れ子→文の分割。遠い前方参照→その場で再掲。具体例のない原理→例とペアにする。
- 保持するもの: 内容の深さ、大人のトーン、正確なterm(termを消すのではなく接地する)。
- auto default候補: 一般公衆向けはELI12前後。分野内documentationは読者の分野知識を確認したうえでAdult〜Expert。

## SNS / short copy

- 支配的制約: C9がほぼ使えない(文脈を持てない)。1 postで自己完結すること。C6は1〜2概念。
- 注意: 省略・内輪の前提・文脈依存の指示語がfloorを最も壊しやすい。スレッド形式でも各postは単独で意味が通ること。
- auto default候補: ELI12前後。ただし分野特化アカウント等のAudience指定があればそれが優先(levels.md優先順位2)。
- 所有しない: バズ・virality、アルゴリズム対応、hashtag・投稿戦略、コピーライティングの巧拙。

## UI / frontend

- 支配的制約: C11(操作・判断の負荷)とC10。同時に提示する選択肢数、ラベルの語彙、状態の可視性、操作結果の予測可能性。
- Levelを下げる操作: 「このボタンを押すと何が起きるか」を推論させない(ラベルで結果を言う)。選択肢を段階化する。状態・エラーを専門語でなく受け手の行動の言葉で示す。エラー文言・確認ダイアログ・同意文もfloorの対象。
- auto default候補: 一般向けproductのUI文言はELI12前後。開発者向けツールは利用者の分野知識を確認したうえでAdult〜Expert。
- 所有しない: visual design、layout、component選定、brand表現。

## diagram / infographic

- 支配的制約: 1図あたりの概念数(C6)、関係線の数と交差、文字への依存度(C10)、凡例と本体の往復(C9)。
- Levelを下げる操作: 1図の関係を絞り、必要なら複数図へ分割する(segmenting)。ラベルは凡例参照でなく要素へ直付けする。装飾的要素を除去する(coherence)。読む順序を視覚的に示す(signaling)。
- Level高: 多要素の図も許容されるが、階層化・グループ化でelement interactivityを下げる。
- auto default候補: 添付先コンテンツのLevelを継承する。

## image

- 支配的制約: C10。読解を要する画像内テキスト量、暗黙のvisual metaphor・記号の前提知識(C1)。
- Levelを下げる操作: 画像単体で主旨が掴めるようにする。文化・分野固有のmetaphorに依存する場合は本文で接地する。画像内の長文を避ける。
- auto default候補: 添付先コンテンツのLevelを継承する。

## video

- 支配的制約: 時間あたりの新規概念数(C6/時間)、因果関係の明示(C5)、巻き戻さないと追えない構造(C9)、視覚だけで追える割合(C10)。
- Levelを下げる操作: 1シーン1概念へ分割する(segmenting)。主要な因果を意図した視聴条件で追えるようにし、音声と画面を併用する場合は矛盾させない。無音視聴を想定する媒体では、必要情報を画面だけでも追えるようにする。章・節の切れ目を示す(signaling)。前提知識は冒頭で宣言する。
- auto default候補: 一般公開の解説はELI12前後。分野内向けはAudienceに従う。
- 所有しない: 撮影・編集技法、演出、尺の最適化。

## short-form video

- 支配的制約: videoの制約に加えて、SNSと同じ自己完結性。冒頭数秒で前提0から入れること。
- 注意: 巻き戻し・再視聴を前提にした高密度構造(高C9)はfloor違反として扱う。1本1主張を基本とし、重要な条件やnuanceは削らず、必要なら自己完結する複数単位へ分ける。
- auto default候補: ELI12前後。
- 所有しない: トレンド対応、hook等のengagement技法、編集技法。
